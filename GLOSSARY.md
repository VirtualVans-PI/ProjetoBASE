# Glossário

> App Glauco · Discovery · Consolidação documental em 28/10/2026 · Aprovação dos itens documentados anteriormente em revisão, por manifestação do responsável pelo projeto.

| Termo | Significado no Discovery |
|---|---|
| Aluno previsto | Aluno esperado no trajeto por configuração contratada, salvo ausência registrada; não equivale a embarque comprovado. |
| Presença confirmada | Situação operacional que não pode ser inferida definitivamente apenas pela localização GPS. |
| Ausência comunicada | Informação da família ou da equipe de que o aluno não utilizará ida, volta ou ambas. |
| Não embarcou | Ocorrência de não embarque; pode exigir correção se o aluno estava atrasado. |
| Ida | Trajeto de transporte para a escola. |
| Volta | Trajeto de retorno da escola. |
| Modalidade de uso | Uso contratado de ida, volta ou ambos; distingue ausência permanente da ocasional. |
| Rota | Percurso operacional nomeado e administrado por Tia Cláudia. |
| Viagem | Execução operacional de uma rota por veículo/motorista em um período. |
| Rota consecutiva | Rota iniciada em sequência a outra, com regras de transição e visibilidade próprias. |
| GPS | Informação de posicionamento da van; sinal auxiliar para lista operacional e acompanhamento autorizado. |
| Indicação preliminar GPS | Sinal automatizado de passagem/parada sujeito a confirmação ou correção humana, não prova de embarque. |
| ETA | Previsão de horário de chegada, sujeita a alterações da viagem. |
| Conta familiar | Conta de acesso que pode ser usada por pai e mãe e vinculada a vários alunos. |
| Responsável principal | Pessoa identificada como principal no cadastro de cada aluno. |
| Recebedor autorizado | Pessoa que família cadastra para receber aluno, sujeito às condições de endereço aprovadas. |
| Competência | Período/mês a que a mensalidade ou lançamento financeiro corresponde. |
| Mensalidade | Cobrança de valor e vencimento negociados individualmente, sem cálculo automático do preço contratado. |
| Quitação | Liquidação integral confirmada da mensalidade; comprovante anexado não equivale a quitação. |
| Excedente | Montante pago além do devido, pendente de decisão administrativa sobre crédito ou devolução. |
| Comprovante | Documento enviado para conferência, com status próprio. |
| Recibo | Documento emitido quando existe quitação integral, com histórico em caso de cancelamento/reemissão. |
| Inadimplência | Mensalidade vencida não quitada; pode gerar alerta, nunca suspensão automática. |
| Suspensão | Decisão manual da administradora de interromper viagens futuras do aluno. |
| Reativação | Decisão manual de retorno após regularização e revisão administrativa aplicável. |
| Desembarque | Momento de entrega do aluno; contingências com recebedor ausente estão em aberto. |
| Lotação | Capacidade máxima registrada do veículo; rota não pode ser liberada acima dessa capacidade. |
| Offline | Operação sem internet com dados previamente carregados e lançamentos sincronizados posteriormente. |
| Conflito de sincronização | Divergência entre registro offline e outro lançamento, resolvida preservando versões e decisão administrativa. |
| Central de avisos | Histórico filtrável de ocorrências e notificações, sem configurar chat interno. |
| FR / BR / NFR | Requisito funcional, regra de negócio e requisito não funcional, respectivamente. |
| DEC / OPEN / AUD | Decisão, questão pendente e achado de auditoria, respectivamente. |
| EPIC / FEAT / US / AC | Épico, feature, história de usuário e critério de aceitação. |

> Quando não houver regra formal de estados, os termos descrevem significado operacional, não uma máquina de estados aprovada.
